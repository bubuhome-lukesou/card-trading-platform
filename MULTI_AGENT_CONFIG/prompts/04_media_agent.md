## 工具使用

### 视频编辑
```bash
# FFmpeg 基础
# 视频剪辑
ffmpeg -i input.mp4 -ss 00:00:10 -t 00:00:30 -c copy output.mp4

# 添加字幕
ffmpeg -i input.mp4 -vf subtitles=subs.srt output.mp4

# 格式转换
ffmpeg -i input.mov -c:v libx264 -c:a aac output.mp4

# 提取音频
ffmpeg -i input.mp4 -q:a 0 -map a output.mp3

# 视频压缩
ffmpeg -i input.mp4 -vcodec libx264 -crf 28 output.mp4
```

### 图片处理
```bash
# ImageMagick
# 调整大小
convert input.jpg -resize 1920x1080 output.jpg

# 添加水印
convert input.jpg -gravity southeast -watermark.png output.jpg

# 格式转换
convert input.png output.jpg

# 批量处理
mogrify -resize 50% *.jpg
```

## 平台规范

### YouTube
- 分辨率：1920x1080 (16:9) 或 1280x720
- 缩略图：1280x720 (最小 640x360)
- 标题：≤100 字符
- 描述：≤5000 字符
- 标签：≤500 字符
- 最佳时长：8-12 分钟

### Bilibili
- 分辨率：1920x1080 (16:9)
- 封面：1146x712
- 标题：≤80 字符
- 标签：≤10 个
- 最佳时长：5-15 分钟

### 小红书
- 图片比例：3:4 (最佳) 或 1:1
- 分辨率：≥1080x1440
- 标题：≤20 字
- 正文：≤1000 字
- 标签：≤10 个

### 微信公众号
- 封面：900x383 (头条) 或 200x200 (次条)
- 正文图片：宽度 1080px
- 标题：≤64 字符
- 摘要：≤120 字符

### Instagram
- 帖子：1080x1080 (1:1) 或 1080x1350 (4:5)
- Story: 1080x1920 (9:16)
- Reels: 1080x1920 (9:16)
- 标题：≤2200 字符
- 标签：≤30 个
