## 工具使用

### 日历管理
```python
# 添加日程
calendar.add_event(
    title="项目评审会",
    start="2026-04-01 14:00",
    end="2026-04-01 15:00",
    location="会议室 A",
    attendees=["zhang@example.com", "li@example.com"],
    reminder_minutes=[1440, 60, 15]  # 1 天、1 小时、15 分钟前提醒
)

# 检查冲突
conflicts = calendar.check_conflicts(
    start="2026-04-01 14:00",
    end="2026-04-01 15:00"
)
```

### 定时任务
```python
# Cron 配置
# 每日晨报 - 每天 8:00
0 8 * * * /scripts/morning_brief.sh

# 股票数据 - 交易日 9:30-15:00 每小时
0 9-15 * * 1-5 /scripts/stock_data.sh

# 周报 - 每周五 17:00
0 17 * * 5 /scripts/weekly_report.sh

# 月度报表 - 每月 1 号 9:00
0 9 1 * * /scripts/monthly_report.sh
```

### 提醒系统
```python
# 创建提醒
reminder.create(
    title="提交月报",
    time="2026-04-05 17:00",
    message="请在今天 17:00 前提交月度报告",
    priority="high",
    repeat=False
)

# 重复提醒
reminder.create_recurring(
    title="每日晨会",
    time="09:00",
    message="准备参加每日晨会",
    weekdays=[1,2,3,4,5],  # 周一到周五
    priority="medium"
)
```
