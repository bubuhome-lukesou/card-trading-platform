# Google OAuth 登入 — 實施記錄 — 2026-09-12

## 完成（commit 206159ae + 部署修復）

### 後端
- user entity + DB：`googleId` 欄位（nullable, unique index）✓
- 安裝 `google-auth-library` ✓
- `POST /auth/google`（GoogleLoginDto: credential）：
  - `verifyIdToken` 驗證 GIS ID token（audience = GOOGLE_CLIENT_ID）
  - 三級查找：googleId → email（老帳號自動綁定 googleId + emailVerified=true）→ 新帳號
  - 新帳號：email（Google 已驗證真實郵箱）/ googleId / nickname 唯一化 / avatar(picture) / 隨機密碼 / role=user
  - 發自家 JWT（復用 generateToken）
- .env 需配置 `GOOGLE_CLIENT_ID`（token 驗證 audience）

### 前端（LoginView）
- 登入表單下加「或」分隔線 + Google 按鈕容器
- GIS SDK 動態載入（accounts.google.com/gsi/client）→ renderButton（filled_blue, continue_with, zh-HK/en）
- credential callback → `POST /auth/google` → setPhoneLogin 復用（同 {user, accessToken} 格式）→ redirectAfterLogin
- 未配置 VITE_GOOGLE_CLIENT_ID 時：顯示 fallback 自繪 Google 按鈕（點擊才載入 SDK，不會報錯）
- SDK 載入失敗顯示 google-error

### DB 遷移（伺服器已執行）
- `ALTER TABLE users ADD COLUMN googleId varchar(255) NULL, ADD UNIQUE INDEX idx_users_google (googleId)` ✓
