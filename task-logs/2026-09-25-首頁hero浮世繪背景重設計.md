## 八輪：波浪單一 renderer 根治交界色差（Luke 追問「一張定兩張背景」，commit `c5b46baa`）
- **Luke 問題命中架構根因**：舊方案兩個 renderer — 場景 SVG 內置波浪（隨寬度拉伸，寬螢幕波浪被放大 25%）+ sea-tile 固定 140px，交界波浪尺度/密度唔同；再加場景底緣漸入實色（波浪淡出）vs tile（波浪即出）；三疊加 = hero/廣告交界色差帶
- **新架構（單一渲染源）**：波浪全頁只由 sea-tile 一個 renderer 畫。hero-ukiyo.svg 改**透明底 overlay**：(1) 天空遮罩 `sky-cover-h` 色帶 = tile 底色疊 CSS 紗幕後嘅**精確最終色**（`#0e111e→#101428→#12162e`，stops 同 CSS 紗幕 0%/38%/72% 對齊）— 場景天空同 tile 區喺任何 x 完全同色 (2) 縱向 mask y 55%→78% 漸放（海平線以下露出 tile 波紋）(3) 霞光加 `glow-kill` mask（y 380→500 歸零）— 實證無呢層霞光殘留造成交界 3% 亮度跳變（PIL 像素量度）(4) 山/霧林/岸帶 `ground-mask` 垂直溶出
- **⚠️ 疊層數學鐵律**：多層背景要無縫，下層（tile）上層（場景遮罩）最終色必須逐 x 精確相等 — 遮罩色 = tile色×(1-紗幕α) + 紗幕色×α，逐段線性插值；場景遮罩必須內建同款紗幕漸變（CSS 紗幕會同時壓場景+tile，單靠 CSS 疊唔會一致）
- **驗證手法（R8 實證有效）**：PIL 合成 tile+紗幕+場景模擬瀏覽器分層 → 像素掃描交界帶 y488-514 每 2px 量 avg，Δ≤2/255（0.8%）過關；真瀏覽器 1280px 截圖目測波浪單一尺度連續
- ⚠️ cairosvg 唔支援 `mix-blend-mode:destination-in`（靜默失敗全白）— 縱向 fade 用 `<mask>` 包 `<g>` 實現
- ⚠️ tile 波紋節拍對位陷阱：合成測試時 tile 波紋弧頂啱啱喺交界露出（y=400 亮點 max=64）似拼接線 — 實為海平線漸現設計意圖，唔係瑕疵；用 scene 底行 vs composite 同 y 像素比對（Δ=0）先係真無縫指標
