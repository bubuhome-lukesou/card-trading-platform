## 🔴 發現並即場修復：重大安全漏洞（commit 3ae31be4）

**RolesGuard 權限檢查完全失效** — `@Roles('admin')` 定義喺 controller **class** 上，但 Guard 只查 **method** 層級 metadata → 查唔到 → 跳過檢查。

**漏洞後果（已實測確認）：** 任何登入用戶（buyer/seller）可以用自己 token 打：
- `GET /admin/stats`（平台統計）✗
- `GET /admin/users`（全部用戶列表）✗
- `PATCH /admin/users/:id`（改任何用戶角色/封禁）✗
- `POST/PUT/DELETE /tags`（亂刪標籤）✗
- `GET /seller-applications/pending`（看申請數據）✗

**修復：** RolesGuard 同時查 `getHandler()` + `getClass()` metadata。
**修復後驗證：** buyer→admin 403 ✓、seller→admin 403 ✓、admin→admin 200 ✓、buyer→tags-create 403 ✓、admin tags CRUD 201 ✓
